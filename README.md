A newspaper poster summing up Friday 20 November 2026 in one image:
the Peace Declaration signed by Trump, Xi and Putin in Shenzhen,
Cyclone Akvan slamming India's Odisha coast, a Russian drone raid
on Kyiv, and Van Gogh's "Chestnut Trees in Blossom" selling for a
record $190.4m at Sotheby's.

`main.py` (Python 3.13, stdlib only) writes the 1024×1024 poster to
`/output/entry.png`. It embeds the image as base64 and verifies its
size and SHA-256 before writing, so both runs produce identical bytes.
